# iTerm profile

`iterm_yash_personal.json` is a **machine-generated** iTerm2 profile export — do
not hand-edit it. Its font is set to `MesloLGS Nerd Font Mono` so which-key and
Starship glyphs render without tofu.

This profile is **not** symlinked by Stow. Import it manually:

> iTerm → Settings → Profiles → Other Actions → Import JSON Profiles

To update it after changing settings in iTerm, re-export over this file
(Other Actions → Save Profile as JSON) and commit the result.
